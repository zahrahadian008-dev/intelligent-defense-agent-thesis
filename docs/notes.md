# خلاصه مقاله Elliptic (Weber et al., 2019)
- **هدف:** شناسایی تراکنش‌های غیرقانونی (پول‌شویی) در بیت‌کوین با استفاده از یادگیری ماشین و شبکه‌های عصبی گرافی (GCN).
- **داده‌ها:** شامل ۲۰۳ هزار گره (تراکنش) و ۱۶۶ ویژگی برای هر گره، دسته‌بندی‌شده به سه کلاس قانونی (Licit)، غیرقانونی (Illicit) و ناشناخته (Unknown).
- **نتیجه کلیدی:** مدل Random Forest بالاترین دقت را در پیش‌بینی داشته اما مدل‌های گرافی (مثل GCN) به دلیل درک روابط میان همسایه‌ها در شبکه، ظرفیت زیادی برای بهبود دارند. همچنین مدل‌ها در برابر تغییر ناگهانی الگوی مجرمان (مثل تعطیلی بازار سیاه) آسیب‌پذیر هستند.
